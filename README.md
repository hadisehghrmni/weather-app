# Weather App 🌤️

A simple weather application developed as part of the JavaScript course entrance challenge at Karyar.

## 📌 About the Project

This project is designed to practice the basics of JavaScript, HTML, and CSS.

The main goal is to learn how JavaScript interacts with HTML elements through the DOM and to build a simple interactive web application.

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## ✨ Features

* Weather information display
* User interaction
* DOM manipulation with JavaScript
* Responsive design

## 📂 Project Structure

```text
weather-app/
│
├── index.html
├── css/
├── js/
└── README.md
```

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
